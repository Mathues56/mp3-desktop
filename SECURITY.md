# Segurança

Não publique vulnerabilidades exploráveis em issues abertas. Após a publicação do repositório, use o canal privado **Report a vulnerability** do GitHub, se habilitado pelo mantenedor. Até haver esse canal, contate o mantenedor por um meio privado conhecido. Não inclua segredos ou arquivos pessoais em relatos. Versão 0.1.0 é a única linha prevista para correções no momento.
