# Regras para agentes

- Leia README e docs/architecture.md antes de alterar o código.
- Entenda o fluxo entre `core`, `storage` e `ui`; preserve funções legítimas.
- Mantenha dependências mínimas e não deixe código temporário ou relatórios supérfluos.
- Nunca inclua credenciais, cookies, músicas de origem desconhecida ou dados privados.
- Execute `python -m unittest discover -s tests -v` após mudanças.
- Atualize README e CHANGELOG quando o comportamento mudar.
- Não anuncie recurso sem teste. Registre limitações com clareza.
- Respeite direitos autorais e termos das fontes. Baixe apenas URLs diretas autorizadas.
- Na interface web, mantenha HTML, CSS e JavaScript alinhados; marque como indisponível qualquer recurso sem implementação real.
- Priorize segurança, manutenção e simplicidade.
