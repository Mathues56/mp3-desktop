# Contribuindo

Leia `docs/architecture.md` e abra uma issue antes de mudanças grandes. Execute `python -m unittest discover -s tests -v` e atualize documentação e CHANGELOG quando mudar o comportamento. Não inclua músicas, cookies, dados privados ou código para contornar restrições de fontes. Pull requests devem explicar o problema, a solução e a validação feita.
